# Publicación en GitHub Pages

Esta carpeta está preparada para subirse tal cual a un repositorio público.

## Flujo de mantenimiento
- Editar `yaml/*.yaml`.
- Hacer commit y push.
- GitHub Actions ejecuta `tools/build.py`.
- GitHub Pages publica la versión actualizada.

## Uso offline
El mismo contenido puede comprimirse en ZIP y abrirse localmente mediante `index.html`.

## Carpeta raíz
No cambiar el nombre `matematikako-laborategia/`.
