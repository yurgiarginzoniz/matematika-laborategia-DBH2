# YAML jardueren iturri nagusia

Aurrerantzean:
1. Jardueraren edukia `yaml/*.yaml` fitxategietan mantentzen da.
2. HTML fitxak YAML horietatik sortutako irteerak dira.
3. Ez da edukia HTMLn bakarrik aldatu behar.
4. Jarraipen historikoa ez da jardueraren YAML honetan gordetzen; nabigatzailearen biltegian gordetzen da.
